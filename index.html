Privacy · Healthcare · Team project

Differential privacy in federated learning

With Shrawani Gulhane and Vasudev Menon, for MA 591, April 2025. The sweep is Fig. 1 at the top of this page.

Question
Can simulated hospitals train a shared mortality model without pooling patient data, and what does adding privacy noise cost?
Data
MIMIC-IV. Patient-level means of six vital signs, undersampled from about 9% positives to a balanced set of 4,726 patients.
Method
Small PyTorch network, FedAvg in Flower over 25 rounds, 7 clients split by demographic group, local DP with update clipping at 5.0 and δ = 1e-5.
Result
Federation matched centralized training (68.4% vs 68.6%). Accuracy sat near chance at ε ≤ 2 and recovered only at ε ≥ 50, a budget that offers weak formal privacy.
Limits
One random seed per run, and small clients swing a lot between rounds. The model is deliberately small, so the trade-off matters more than the absolute accuracy.

Document AI · NC State research

Reading invoices with a fine-tuned Donut transformer

Layout variety was the main thing limiting automated extraction. Fig. 2 shows why, using the project's own labels.

Question
Can one model read invoices across many layouts without a separate OCR step?
Data
10,000 synthetic invoices from 50 templates, 200 each, with 32 labeled field types.
Method
Fine-tuned donut-base with PyTorch Lightning and benchmarked it against traditional OCR. Scored with exact JSON match, BLEU, ROUGE, and per-field precision, recall and F1.
Result
Extraction accuracy rose 23% over baseline.
Limits
The invoices are synthetic, so real scans would be harder. The raw images are too large for the repository, which holds the labels and code.

A small specialist model writes a short description of each vulnerability, and a code LLM patches the function with and without that hint.

Question
